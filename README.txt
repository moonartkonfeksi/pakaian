MOONART KONFEKSI — WEBSITE MULTI-PAGE
====================================

Website sekarang menggunakan halaman/file HTML TERPISAH, bukan hanya scroll
antar-section pada satu halaman.

STRUKTUR:
- index.html              Beranda
- tentang-kami.html       Tentang Kami
- produk.html             Daftar semua produk
- produk/kaos.html        Detail Kaos
- produk/kaos-polo.html   Detail Kaos Polo
- produk/rompi.html       Detail Rompi
- produk/jas.html         Detail Jas
- produk/jaket.html       Detail Jaket
- produk/jersey.html      Detail Jersey
- produk/kemeja.html      Detail Kemeja
- produk/koko.html        Detail Koko
- produk/totebag.html     Detail Totebag
- portofolio.html         Portofolio
- kontak.html             Hubungi Kami
- style.css               CSS bersama
- script.js               JavaScript navigasi/menu
- assets/                 Gambar dan logo

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder moonart-multipage di VS Code.
3. Jalankan index.html dengan ekstensi Live Server.
4. Klik menu Portofolio, Tentang Kami, Produk, atau Hubungi. Browser akan
   membuka file HTML berbeda dengan URL/halaman masing-masing.

WHATSAPP:

CATATAN:
- Link Instagram/TikTok/Facebook masih URL umum; ganti dengan akun resmi.
- Gambar produk menggunakan crop dari referensi yang dikirim. Ganti dengan
  foto produksi asli saat tersedia.
- Deskripsi teknis, harga, minimum order, alamat, dan data perusahaan belum
  ditambahkan karena belum diberikan. Detail produk sengaja ditulis sebagai
  informasi umum agar tidak mengarang spesifikasi.
- Website statis HTML/CSS/JS; tidak memakai database/CMS.
